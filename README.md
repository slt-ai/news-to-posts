# Генератор постов по новостям ✍️

Локальный веб-сервис: вставляешь ссылку на новость или статью про ИИ и компьютерные технологии — приложение скачивает страницу, достаёт текст, отправляет его облачной языковой модели **Ollama Cloud** вместе с настройками «голоса» и настроением. Модель пишет оригинальный пост для соцсетей, а ты копируешь его одной кнопкой.

---

## Возможности

- 🧠 Генерация поста по любой статье: ссылка → текст страницы → готовый пост.
- 🎭 **Настроение поста** — шесть «чипов»: радостное, восторженное, вдохновляющее, игривое, интригующее, деловое.
- 🗣 **Голос поста** — тон, длина, количество эмодзи и стиль заголовка настраиваются в файле `voice.md`.
- 🤖 **Выбор модели** — список облачных моделей Ollama с ценами прямо на странице.
- 📋 Кнопка «Скопировать пост» с запасным вариантом копирования для старых браузеров.
- 🛟 Fallback: если сайт блокирует автоматическое чтение (403/401/498 — защита от ботов), можно описать суть новости своими словами, и пост соберётся по описанию.

## Технологии

- Python 3 · Flask · requests · BeautifulSoup · python-dotenv
- Облачное API: [Ollama Cloud](https://ollama.com) (`/api/chat`)

## Установка и запуск

### 1. Требования

- **Python 3.10+** ([python.org](https://www.python.org/downloads/)) — при установке на Windows отметь галочку **«Add python.exe to PATH»**.
- **Git** (в любой ОС) или просто скачать архив репозитория.

### 2. Склонируй проект

```bash
git clone https://github.com/slt-ai/news-to-posts.git
cd news-to-posts
```

### 3. Получи ключ API Ollama

1. Зарегистрируйся на [ollama.com](https://ollama.com) — у аккаунтов есть бесплатные кредиты.
2. Создай API-ключ: [ollama.com/settings/keys](https://ollama.com/settings/keys) (именно API-ключ, не SSH).
3. Скопируй его — он понадобится на шаге 5.

### 4. Создай виртуальное окружение и установи зависимости

**Windows (PowerShell или командная строка):**

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### 5. Настрой `.env`

Скопируй шаблон и открой его в редакторе:

**Windows:**

```powershell
copy .env.example .env
notepad .env
```

**macOS / Linux:**

```bash
cp .env.example .env
```

Впиши свой ключ вместо пустого значения:

```
OLLAMA_API_KEY=твой_ключ_здесь
```

Остальные настройки (хост, порт, `DEBUG`, модель по умолчанию) можно оставить как есть. Файл `.env` уже добавлен в `.gitignore` — он не попадёт в Git.

### 6. Запусти

**Windows — в один клик:** просто запусти `start.bat`.

**Или вручную (любая ОС):**

```bash
python app.py
```

Теперь открой в браузере: **http://127.0.0.1:5000**

> Не закрывай окно, где запущен сервер, пока пользуешься сайтом.

## Как пользоваться

1. Вставь ссылку на новость или статью про ИИ / технологии в первое поле.
2. *(Необязательно)* Допиши своими словами важные акценты или своё мнение — модель учтёт это.
3. Выбери **настроение поста** (чип-эмодзи).
4. Выбери **модель** — на странице показано имя и цена за миллион токенов.
5. Нажми **«Сформировать пост»**.
6. Когда пост готов — нажми **«Скопировать пост»** и вставь его куда захочешь.

### Если сайт «не открывается»

Многие новостные и магазинные сайты (Wildberries, DNS-шоп, часть СМИ) блокируют скриптовые GET-запросы и возвращают коды **401 / 403 / 498** — это защита от ботов, а не баг. Решение:

- опиши суть новости **своими словами** в поле «Дополнительно о новости»;
- нажми «Сформировать пост» — пост соберётся по твоему описанию (страница появится уведомление об этом).

## Настройка «голоса» поста (`voice.md`)

Файл читается при каждом поколении. Формат — `КЛЮЧ: значение`, строки с `#` — комментарии:

| Ключ | Допустимые значения |
|---|---|
| `ТОН ПОСТА` | дружелюбный, официальный, весёлый, вдохновляющий, дерзкий, … |
| `ДЛИНА ПОСТА` | короткий, средний, длинный |
| `КОЛИЧЕСТВО ЭМОДЗИ` | число от 0 до 5 |
| `СТИЛЬ ЗАГОЛОВКА` | заглавные буквы, обычный |

## Модели и цены

По умолчанию стоит **Gemma 4** — пишет пост сразу. Актуальные цены и список моделей: [ollama.com/pricing](https://ollama.com/pricing).

Модели с режимом «мышления» (например, GPT-OSS, GLM) могут тратить лимит токенов на внутренние рассуждения и выдавать пустой или «ломаный» ответ — поэтому запрос всегда отправляется с параметром `think: false`.

## Устранение проблем

| Проблема | Решение |
|---|---|
| `OLLAMA_API_KEY` не заполнен | Впиши ключ в `.env` (без пробелов и кавычек): [ollama.com/settings/keys](https://ollama.com/settings/keys) |
| `401` при запросе к модели | Неверный/неактивный ключ — проверь, что скопирован целиком |
| `403` | Модель недоступна на твоём тарифе — выбери другую или пополни баланс |
| `429` | Закончились кредиты или слишком много запросов — подожди |
| Сайт блокирует чтение страницы | Опиши новость своими словами (см. выше) |
